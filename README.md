# 💝 PRESENTEISA

### *Um site especial para celebrar nossos momentos juntos*

</div>

## 📖 Sobre o Projeto

Site desenvolvido como presente, mostrando o contador de dias do nosso relacionamento e uma galeria com nossas memórias especiais. Um projeto pessoal feito com carinho para eternizar nossos momentos.

## ✨ Funcionalidades

- ⏰ **Contador de dias** - Acompanha quantos dias estamos juntos
- 📸 **Galeria de fotos** - Memórias dos nossos melhores momentos
- 💌 **Seções especiais** - Detalhes, memórias e vales-presente personalizados
- 🎨 **Design responsivo** - Acesso de qualquer dispositivo

## 🗂️ Estrutura do Projeto

```
PRESENTEISA/
│
├── index.html          # Página principal com contador
├── detalhes.html       # Detalhes especiais
├── memorias.html       # Galeria de memórias
├── renovacao.html      # Seção de renovação
├── vales.html          # Vales-presente
└── imagens/            # Pasta com as fotos
```

## 🚀 Como Visualizar

1. Clone o repositório:
```bash
git clone https://github.com/MatheusMeirellesGomes/PRESENTEISA.git
```

2. Navegue até a pasta do projeto:
```bash
cd PRESENTEISA
```

3. Abra o arquivo `index.html` no seu navegador preferido
